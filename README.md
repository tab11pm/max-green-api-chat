# MAX chat through GREEN-API

A local React and TypeScript demo. This scaffold currently shows the connection screen heading; chat functionality is under development.

Use Node.js 22.12 or newer in the 22.x line, Node.js 24.x, or Node.js 26+.

```sh
npm install
npm run dev
```

Run `npm run test -- --run` for the test suite and `npm run build` for a production bundle.

Credentials will be held only in React memory and will disappear on refresh. The direct browser integration is intended for local evaluation; a production deployment needs a backend session proxy to keep GREEN-API credentials out of browser requests.
