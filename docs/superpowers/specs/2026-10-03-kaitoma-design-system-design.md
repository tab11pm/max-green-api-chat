# Кайтома — дизайн-система и редизайн чата

## Цель

Применить эстетику референса WhatsApp (`docs/superpowers/DESIGN.md`) к интерфейсу
чата MAX через GREEN-API: тёплый cream-фон, уверенная типографика, мягкие
пилюли, отсутствие теней. Переименовать продукт в **«Кайтома»** и заменить
единственный хроматический акцент на фирменный **градиент MAX**. Результат —
согласованный light/dark интерфейс, собранный из существующих компонентов, без
изменения архитектуры, хуков, API и политики хранения данных.

## Границы

- Меняется только визуальный слой: `src/styles.css`, классы и небольшие правки
  разметки в пяти компонентах, `index.html`, а также тесты, проверяющие
  изменённую копию.
- Копирайт: захардкоженный «WhatsApp» в интерфейсе заменяется на «MAX»,
  продукт называется «Кайтома».
- Добавляются: компонент переключателя темы и inline-инициализация темы.

## Вне границ

- Маркетинговый лендинг, editorial-фотографии, 80px hero, иллюстрации.
- Изменение архитектуры, роутинга, API, модели данных, мультичатовости.
- Публичный хостинг, бэкенд-прокси, новые продуктовые функции.

## Принципы

1. **Cream виден.** Тёплый фон `#fcf5eb` — базовая поверхность приложения, а не
   редко используемый резерв.
2. **Один акцент.** Единственный хроматический сигнал — градиент MAX. Он
   используется только для действий, активного состояния, логотипа и исходящих
   сообщений.
3. **Без теней.** Глубина создаётся контрастом поверхностей (cream → white) и
   hairline-границей `1px`, а не `box-shadow`.
4. **Пилюли и мягкие радиусы.** Все интерактивные элементы — pill или скругление
   ≥ 16px; острые углы не используются.
5. **Крупная, но прикладная типографика.** Дисплейный масштаб референса
   сохранён для экрана подключения и пустых состояний, но переведён в
   приложении на рабочие размеры.

## Токены — цвет

Все токены имеют префикс `--k-` и определены в `:root` (light) и переопределены
для тёмной темы.

### Light (по умолчанию)

| Токен | Значение | Роль |
|-------|----------|------|
| `--k-canvas` | `#fcf5eb` | Фон страницы и поверхности чата |
| `--k-surface` | `#ffffff` | Карточки, панели, сайдбар, хедер, композер, входящие бабблы |
| `--k-surface-2` | `#f0f4f9` | Поля ввода, превью чата |
| `--k-text` | `#1c1e21` | Основной текст |
| `--k-ink` | `#111b21` | Максимально контрастный текст и иконки |
| `--k-muted` | `#5e5e5e` | Вторичный текст, подсказки, время |
| `--k-accent` | `#0060cc` | Ссылки, focus, активные метки (MAX blue, затемнён для контраста ≥ 4.5:1) |
| `--k-border` | `rgba(28,30,33,.10)` | Hairline-границы и разделители |

которых даёт контраст с белым текстом ≥ 4.5:1. Это проверяется автотестом
`src/domain/contrast.test.ts`.

## Токены — типографика

Максимальный шрифт `Max Sans` публично недоступен, поэтому используется **Inter**
(та же замена, что предлагает референс) с системным fallback. Веса: 400, 600, 700.

| Токен | Размер / интерлиньяж / вес | Роль |
|-------|----------------------------|------|
| `--k-text-display` | 48px / 1.1 / 700 | Экран подключения, пустые состояния |
| `--k-text-heading` | 32px / 1.15 / 700 | Крупные заголовки |
| `--k-text-title` | 20px / 1.3 / 700 | Заголовок чата и диалога |
| `--k-text-body-lg` | 18px / 1.4 / 400 | Подзаголовки, вводный текст |
| `--k-text-body` | 16px / 1.4 / 400 | Сообщения, поля, кнопки |
| `--k-text-label` | 14px / 1.4 / 600 | Метки полей |
| `--k-text-caption` | 12px / 1.4 / 400 | Время, подсказки, eyebrow |

## Токены — отступы, радиусы, глубина

- Базовая единица — 4px; шкала `--k-space-4…--k-space-64` (4, 8, 12, 16, 20, 24,
  32, 40, 48, 64).
- Радиусы: `--k-radius-pill: 9999px`; `--k-radius-composer: 24px`;
  `--k-radius-panel: 20px`; `--k-radius-card: 16px`;
  `--k-radius-media: 25px`; бабблы `16px` с хвостовым углом `4px`.
- `box-shadow` не используется нигде. Глубина — только поверхности и границы.

## Тёмная тема

- Значение по умолчанию — системное: `@media (prefers-color-scheme: dark)`
  переопределяет токены.
- Ручной тумблер выставляет `data-theme="dark"` на `<html>`, что переопределяет
  токены независимо от системной темы. Выбор хранится в
  `localStorage['kaitoma-theme']` (`'light' | 'dark'`); ничего кроме темы там не
  хранится.
- В `index.html` добавляется минимальный inline-скрипт, применяющий тему до
  первой отрисовки, чтобы не было вспышки. Атрибут ставится только для валидного
  сохранённого значения (`'light' | 'dark'`); при отсутствии или повреждённом
  значении атрибут не ставится, и тему выбирает CSS через
  `prefers-color-scheme`.
- `meta name="color-scheme"` и `color-scheme` в CSS синхронизированы с темой.

## Иконография

Единая система контурных иконок: inline SVG в React-компоненте `Icon`, без новых
зависимостей. Параметры: `viewBox 0 0 24 24`, `stroke: currentColor`,
`fill: none`, `stroke-width: 1.75`, скруглённые окончания; размер по умолчанию
`20px`, есть варианты `16px` и `24px`. По умолчанию иконка `aria-hidden`;
когда иконка — единственное содержимое кнопки, доступное имя задаётся
`aria-label` на кнопке.

Набор (17): `plus`, `chat`, `logout`, `sun`, `moon`, `plug`, `shield`, `id-card`,
`lock`, `phone`, `send`, `arrow-right`, `check-check`, `clock`, `more`, `close`,
`search`.

Применение:

- Экран подключения: `shield` в tagline, `plug` в eyebrow, `id-card` и `lock` в
  метках и внутри полей, `arrow-right` в CTA.
- Переписка: `chat` в пустом состоянии и в поле композера, `phone` рядом с
  номером, `close` в кнопке «Закрыть чат», `send` в круглой кнопке отправки.
- Бабблы: `clock` у входящих, `check-check` у исходящих — рядом со временем.
- Сайдбар: `sun`/`moon` в тумблере темы, `logout` у «Отключиться».

`search` и `more` включены в набор как зарезервированные, но **не размещаются в
интерфейсе**, пока нет соответствующих функций (поиск и меню «Ещё» вне границ).
Не вводим неработающие элементы управления.

## Компоненты

### ConnectionScreen

Cream-фон. По центру колонка до 420px: логотип «К» на градиенте (60px, радиус
16px), `h1` «Кайтома» в display, tagline body-lg в `--k-muted`. Белая панель
(радиус 20px, hairline, padding 32px) с eyebrow «GREEN-API · MAX», заголовком
`h2` «Подключение к GREEN-API» (текст сохранён для совместимости с тестами),
полями-pill на `--k-surface-2` (ведущая иконка внутри поля) и кнопкой-градиентом
на всю ширину со стрелкой. В tagline и eyebrow — иконки `shield` и `plug`.

### ChatScreen

Двухколоночная оболочка: сайдбар `250px` на white с hairline-границей справа и
поверхность чата на cream, чтобы бабблы «плавали». Хедер белый с hairline снизу:
заголовок-номер, статус транспорта с цветной точкой **и** текстом, кнопка
«Закрыть чат» в виде icon-кнопки (`close`). Рядом с номером — иконка `phone`,
аватар с инициалами. Пустое состояние — градиентная иконка `chat` и heading.

### MessageTimeline

Входящий баббл — белый (`--k-surface`) с `--k-text` и hairline. Исходящий —
градиент с белым текстом. Внизу — `time` в caption (входящий: `--k-muted`,
исходящий: `rgba(255,255,255,.78)`). Видимая подпись «Входящее сообщение» /
«Исходящее сообщение» становится визуально скрытой, но остаётся в DOM для
доступности (и для существующего теста).

Время берётся из поля `timestamp` сообщения; форматируется в `ЧЧ:ММ` по
локальному времени.

### Composer

Белая полоса с hairline сверху. `textarea` на `--k-surface-2`, радиус 24px, с
ведущей иконкой `chat`; кнопка «Отправить» — круглая градиентная icon-кнопка
`send` с `aria-label="Отправить"`. Метка «Сообщение» остаётся для доступности.
Состояния `sending` и ошибки сохранены.

### NewChatDialog

Тёплый затемняющий backdrop, белая панель (радиус 20px), заголовок `title`,
pill-поле телефона с ведущей иконкой `phone`, градиентная отправка со стрелкой и
ghost-кнопка отмены; закрытие — icon-кнопка `close`. Фокус-трап, Escape и
`role="dialog"` не меняются.

### ThemeToggle

Небольшая icon-кнопка (`moon` / `sun`), переключающая `data-theme` и записывающая
выбор. Доступное имя — `aria-label="Переключить тему"`, `title` сообщает текущее
действие. Размещается в шапке сайдбара справа от бренда и отдельно на экране
подключения. «Отключиться» — не соседствует с тумблером: это отдельная
full-width строка-футер внизу сайдбара, отделённая hairline, с иконкой `logout`.

### Логотип

Плашка «К» на градиенте со скруглением 16px плюс вордмарк «Кайтома». Eyebrow —
«GREEN-API · MAX».

## Копирайт и метаданные

- `index.html`: `<title>Кайтома — MAX чат через GREEN-API</title>`, `lang="ru"`,
  `color-scheme`, подключение Inter.
- «WhatsApp чат» → «Чат MAX».
- Тексты проверки номера: «…не зарегистрирован в WhatsApp…» → «…в MAX…».
- Прочие упоминания «WhatsApp» в видимом интерфейсе заменяются на «MAX».
  Внутренние идентификаторы API (`checkWhatsapp`) не переименовываются.

## Доступность

- `:focus-visible` — кольцо `3px` цвета `--k-accent` с отступом.
- Контраст текста ≥ 4.5:1 в обеих темах; градиент подобран под белый текст.
- Статус транспорта и ошибки не передаются только цветом — есть текст.
- `prefers-reduced-motion` отключает переходы/анимации.
- Тумблер темы имеет понятное доступное имя и не зависит только от иконки.

- `src/components/ConnectionScreen.tsx`, `ChatScreen.tsx`, `MessageTimeline.tsx`,

- `src/components/ThemeToggle.tsx` — новый небольшой компонент; рендерится внутри
  `ConnectionScreen` и `ChatScreen`.
- `src/App.tsx` — не меняется.
- `index.html` — заголовок, шрифт, `color-scheme`, inline-инициализация темы.
- Тесты: `src/App.test.tsx`, `src/components/ConnectionScreen.test.tsx`,
  `src/components/ChatScreen.test.tsx` — обновляются проверки изменённой копии

## Тестирование

- Юнит- и компонентные тесты продолжают покрывать логику; обновляются только
  утверждения о копии/заголовках.
- Новый тест: тумблер темы переключает `data-theme` и пишет значение в
  `localStorage` (и что тема применяется из сохранённого значения).
- Визуальная проверка вручную: экран подключения, пустое состояние, переписка,
  диалог нового чата — в light и dark.

## Проверка

- `npm run test -- --run`
- `npm run build`
- Ручной прогон: подключение → новый чат → отправка → входящее; переключение
  темы; проверка контраста и фокуса.

## Принятые решения

- Типографика — Inter через Google Fonts (с системным fallback).
- Тумблер темы присутствует; тема запоминается в `localStorage` (только тема).
- Исходящие бабблы — градиентные; входящие — белые.
- Видимая подпись типа сообщения скрыта визуально, остаётся для accessibility.
- Время сообщения показывается в баббле, с иконкой часов у входящих и галочек у
  исходящих.
- Иконки — собственный inline SVG-набор (16 иконок), без сторонних библиотек.
- Иконки `search` и `more` зарезервированы в наборе, но не добавляются в UI, пока
  нет соответствующих функций.
