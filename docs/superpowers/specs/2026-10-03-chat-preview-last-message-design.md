# Последнее сообщение в превью чата

## Цель

В левом списке чатов под номером телефона показывать текст последнего сообщения вместо служебного статуса активности.

## Поведение

- Для каждого чата берётся последний элемент массива `messages`.
- Под номером отображается его поле `text` без префиксов направления и без статусов «Текущий чат» или «Сохранённый чат».
- Длинный текст остаётся на одной строке и визуально обрезается многоточием.
- У чата без сообщений подзаголовок не рендерится.
- Доступное имя кнопки чата остаётся номером телефона.

## Проверка

- Тест проверяет отображение последнего текста при нескольких сообщениях.
- Тест проверяет отсутствие подзаголовка у пустого чата.
